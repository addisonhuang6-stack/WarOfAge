# WarOfAge

基于 Godot 4.7 的极简即时战略 Demo，分为宏观世界地图与微观战术战斗两层。

## 玩法

- 主菜单：选择语言（中文 / English）、声音、人机 AI 开关、游戏速度（0.5× / 1× / 2× / 3×）和地图（随机 / 沙漠 / 草原 / 高山）。
- 宏观战略：在世界地图上移动己方军队；双方最前线军队的接触点连成 War of Dots 式动态边境线；己方与敌方军队接触后进入微观战斗。军队越过战线深入敌后会形成包围圈，并显示补给中断与短缺，撤回后恢复。世界地图分为草原、沙漠和高山区域，接战地点决定微观战场的地形。
- 微观战术：划线移动、框选、兵种克制（长矛兵反骑）、自动近战；战斗结束后按 Enter 返回世界地图，败方军队被消灭。

## 运行

1. 使用 Godot 4.7 打开本目录中的 `project.godot`。
2. 按 F5 运行，主场景为 `scenes/main_menu.tscn`。

## 操作

**宏观**

- 左键选择己方军队，再点击地图下达移动命令。
- 世界地图上的半透明色块和文字标出各地形区域；最前线军队形成黑色动态边境线，深入敌后的军队周围会出现黑色包围圈。
- 选中军队后 HUD 会显示编号、补给百分比与补给状态。
- P / 空格暂停，`[` / `]` 调整游戏速度。
- Esc 返回主菜单。

**微观**

- 左键点选单位；未选中部队时拖拽框选。选中部队后，在任意位置（包括单位身上）按住左键划线即可沿路径前往，移动路径会保留在地面上。
- 微观开局双方各 50 名长矛兵和 20 名轻骑兵，单位以很小的几何标记显示。
- 滚轮 / 双指缩放，中键拖动或 WASD/方向键平移视角。
- P / 空格暂停，`[` / `]` 调整游戏速度；HUD 会显示已选兵种构成。
- 长矛兵是「实心圆 + 内三角」标记，轻骑兵是三角标记；三角尖端表示朝向。
- C：选中轻骑兵后直线冲锋，基础速度 5，约 4 秒加速到最高 7；冲锋基础伤害为质量 × 速度（质量为 5），再减去目标护甲；动量减去目标韧性大于 0 时推挤并进入奋战。友军会自动让开，路径上留下灰白尘土。
- 长矛兵遇到敌方步兵会自动吸附一个敌人进入奋战；骑兵冲锋动能耗尽后也会自动锁敌。
- 多选单位时地图上会显示方阵预览，移动时自动排成方阵；敌方 AI 可在主菜单开关，开启后会成建制向你的部队推进。
- T：选中当前单位的全部同类型单位；Ctrl+1~9 编队，1~9 选择编队。
- Ctrl+按住左键拖拽：画出防御线，选中单位会自动沿线展开并面向最近敌军；放不下的单位会按相同宽度排到后方。
- 单位拥有实体体积，不会互相堆叠；长矛兵移动速度较慢，轻骑兵负责机动与冲锋。
- 不再显示伤害数字，单位受伤后会出现裂纹（生命低于 75% / 50% / 25% 时逐步增加）。
- 长矛兵有方向性：被从背后攻击时护甲仅剩 30%，侧面受击时护甲剩 60%；自己从侧面或背后攻击敌人时，伤害只剩 20%。
- 基础数值：长矛兵生命 200 / 攻击 10 / 护甲减免 10 / 韧性 10 / 速度 2；轻骑兵生命 200 / 攻击 15 / 护甲减免 10 / 速度 5 / 冲锋最高 7 / 质量 5。
- R 重开战斗；战斗结束后按 Enter 返回世界地图。
