# WarOfAge

基于 Godot 4.7 的极简即时战略 Demo，分为宏观世界地图与微观战术战斗两层。

## 玩法

- 主菜单：选择语言（中文 / English）、声音和地图（随机 / 沙漠 / 草原 / 高山）。
- 宏观战略：在世界地图上移动己方据点；补给线从补给站经友军链式传递，敌人可以切断连线；己方与敌方据点接触后进入微观战斗。
- 微观战术：划线移动、框选、兵种克制（长矛兵反骑）、自动近战；战斗结束后按 Enter 返回世界地图，败方据点被消灭。

## 运行

1. 使用 Godot 4.7 打开本目录中的 `project.godot`。
2. 按 F5 运行，主场景为 `scenes/main_menu.tscn`。

## 操作

**宏观**

- 左键选择己方据点，再点击地图下达移动命令。
- Esc 返回主菜单。

**微观**

- 左键点选单位；未选中部队时拖拽框选。选中部队后，在任意位置（包括单位身上）按住左键划线即可沿路径前往，移动路径会保留在地面上。
- 微观开局双方各 50 名长矛兵和 20 名轻骑兵，单位以很小的几何标记显示。
- 滚轮 / 双指缩放，中键拖动平移视角。
- 长矛兵是「实心圆 + 内三角」标记，轻骑兵是三角标记；三角尖端表示朝向。
- C：选中轻骑兵后直线冲锋，约 4 秒加速到最高速度；高速撞击会推开韧性较低的士兵并降低冲锋速度，友军会自动让开，路径上会留下灰白尘土。
- 长矛兵遇到敌方步兵会自动吸附一个敌人进入奋战；骑兵冲锋动能耗尽后也会自动锁敌。
- 部队移动时按当前相对位置保持队列；敌方 AI 会成建制向你的部队推进。
- T：选中当前单位的全部同类型单位；Ctrl+1~9 编队，1~9 选择编队。
- Ctrl+按住左键拖拽：画出防御线，选中单位会自动沿线展开并面向最近敌军；放不下的单位会按相同宽度排到后方。
- 单位拥有实体体积，不会互相堆叠；长矛兵移动速度较慢，轻骑兵负责机动与冲锋。
- 长矛兵有方向性：被从背后攻击时护甲仅剩 30%，侧面受击时护甲剩 60%；自己从侧面或背后攻击敌人时，伤害只剩 30%。
- R 重开战斗；战斗结束后按 Enter 返回世界地图。
